# Hello TypeScript

A generic TypeScript learning project. This is the beginning, not a finished release: I’ll add examples and TypeScript building blocks as I learn.

## Getting Started

Install the dependencies:

```sh
npm install
```

Run the example:

```sh
npx tsx src/index.ts
```

Compile the TypeScript files into `dist/`:

```sh
npx tsc
```

Then run the compiled program with Node.js:

```sh
node dist/index.js
```

## Project Structure

```text
src/
	index.ts   # Example program
	math.ts    # Small math example
```

More examples and notes will be added as the project grows.
